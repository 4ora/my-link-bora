# 마이링크 (MyLink) 와이어프레임 (Wireframe)

본 문서는 마이링크 서비스의 핵심 화면인 **마이페이지(소유자 관리 화면)**와 **퍼블릭 페이지(방문자 화면)**의 구조를 ASCII 아트로 시각화한 와이어프레임입니다. 반응형(데스크탑/모바일) 레이아웃 구조를 모두 포함합니다.

---

## 1. 마이페이지 (소유자 전용 관리 화면)

소유자가 로그인 직후 보게 되는 화면입니다. 우측 상단에 고정된 메뉴와, 인라인 편집(✏️)이 가능한 직관적인 인터페이스를 제공합니다.

## 3. 핵심 UI 요소 상세 설명

1. **내 페이지 보기 버튼 (고정 헤더)**
   - 스크롤을 내려도 항상 우측 상단에 고정되어 있어, 소유자가 편집을 마친 후 즉시 실제 반영된 화면을 확인할 수 있도록 유도합니다.
2. **인라인 편집 (✏️ 연필 아이콘)**
   - 모달(Modal) 창이나 별도의 페이지 이동 없이, 텍스트(닉네임, 소개글, 링크 제목, URL)를 클릭하면 그 자리에서 바로 입력창(Input)으로 변환되어 직관적인 수정이 가능합니다.
3. **파비콘 (자동 생성 아이콘)**
   - 사용자가 URL을 입력하면 API가 도메인을 인식하여 해당 웹사이트의 대표 아이콘(파비콘)을 링크 버튼 좌측에 자동으로 렌더링합니다. (이미지 업로드 생략)

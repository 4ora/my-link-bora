# 제품 요구사항 정의서 (PRD) - 마이링크 (MyLink)

## 1. 프로젝트 개요
- **프로젝트명:** 마이링크 (MyLink)
- **목적:** 개발자 및 크리에이터가 자신의 다양한 활동 링크(포트폴리오, 소셜 미디어, 블로그 등)를 하나의 페이지에 모아서 공유할 수 있는 심플하고 직관적인 링크 관리 서비스 구축.
- **대상 사용자:** 복잡한 기능 없이 깔끔하게 자신의 링크를 관리하고 싶은 개발자 및 크리에이터.

## 2. 기술 스택 및 디자인 원칙
- **UI/UX:** Shadcn/ui 컴포넌트 활용
- **디자인 컨셉:** 추후 적용될 자체 디자인 시스템 기반 적용 (현재 커스텀 테마 기능은 제공하지 않음)
- **인증 방식:** Firebase를 활용한 구글(Google) 소셜 로그인 (단일 인증)
- **데이터베이스:** Firebase Firestore (서브 컬렉션 구조 활용)

---

## 3. 핵심 기능 목록 (필수 기능만 포함)

모든 선택/부가 기능(테마, 방문자 통계, 모바일 미리보기, 드래그앤드롭 등)은 본 PRD 범위에서 제외되었으며, 오직 필수(Core) 기능만을 명시합니다.

### 3.1. 사용자 인증 및 계정 생성
- **구글 소셜 로그인:** 사용자는 구글 계정으로만 가입 및 로그인이 가능합니다.
- **초기 계정 세팅:** 
  - 회원가입 시 구글 이메일(Gmail)의 아이디 앞부분을 파싱하여 **디스플레이 네임(displayName)**으로 자동 설정합니다.
  - 이 `displayName`은 유저의 고유 URL 슬러그로 사용됩니다. (예: `user@gmail.com` -> `도메인.com/user`)
  - URL 경로에는 `@` 기호를 포함하지 않습니다.

### 3.2. 프로필 관리 기능 (인라인 편집)
- **프로필 정보 노출 및 수정:** 
  - **유저 네임(Username):** 실제 사용자의 이름(Real name)을 보여주는 필드입니다. 
  - **디스플레이 네임(displayName):** URL 슬러그로 사용되는 고유 아이디 값입니다.
  - **한 줄 소개(Bio):** 개발자/크리에이터로서 자신을 표현할 수 있는 짧은 소개글 필드입니다.
  - 유저 네임, 디스플레이 네임, 한 줄 소개는 마이페이지에서 **인라인 편집(Inline Editing)** 방식으로 즉시 수정할 수 있습니다.
  - *참고: 이미지 업로드 기능은 제공하지 않습니다.*

### 3.3. 링크 관리 기능 (인라인 편집)
- **링크 추가 및 인라인 수정:**
  - 사용자는 새로운 링크(URL 및 링크 타이틀)를 추가할 수 있습니다.
  - 생성된 링크의 텍스트나 URL을 클릭하여 즉시 수정할 수 있는 인라인 편집 기능을 제공합니다.
- **파비콘 자동 적용:**
  - 사용자가 링크 URL을 입력하면, 구글 파비콘 API(Google Favicon API)를 활용하여 해당 도메인의 파비콘을 자동으로 불러와 링크 아이템의 아이콘으로 표시합니다.
- **링크 삭제:** 등록된 링크를 삭제할 수 있습니다.
- **링크 정렬 기준:** 드래그 앤 드롭 순서 변경 기능이 없는 대신, 화면에 보여질 때는 **'가장 최근에 추가한 링크가 위로 오도록(최신순)'** 정렬하여 노출합니다.
- *제외된 기능:* 링크 활성화/비활성화, 드래그 앤 드롭 순서 변경, 이미지/썸네일 직접 업로드.

### 3.4. 데이터베이스 모델링 (Firestore)
- **Users Collection:**
  - `uid` (문서 ID)
  - `displayName` (URL 슬러그, 이메일 앞부분 기반)
  - `username` (실제 표시될 유저 이름)
  - `bio` (한 줄 소개)
  - `email` (구글 소셜 로그인 전용)
  - **Sub-collection: `links`**
    - `linkId` (문서 ID)
    - `title` (링크 제목)
    - `url` (연결될 주소)
    - `createdAt` (생성일자, 최신순 정렬에 사용됨)
